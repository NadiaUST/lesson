# 📚 Учебный репозиторий по JavaScript 

Этот репозиторий — моя учебная площадка, где я шаг за шагом изучаю JavaScript и веб-разработку.  
Каждый урок, домашка или эксперимент оформлены в отдельных ветках: так удобно возвращаться, сравнивать код и отслеживать прогресс.

---

## 🔥Что внутри

- Практика по JavaScript:
  - переменные и типы данных  
  - условия и логические операторы  
  - функции  
  - массивы и методы массивов  
  - объекты  
  - циклы  
  - работа с DOM  
  - мини-проекты и домашние задания  

- Каждая тема — в отдельной ветке  
  (например: `lesson-8`, `lesson-17` и т.д.)

- Ветки содержат:
  - учебные задания  
  - решения  
  - эксперименты  
  - тестовые HTML/JS файлы  
  - мини-дебаг проектов

---

## 🧠 Зачем этот репозиторий

- чтобы наглядно видеть свой рост    
- легко возвращаться к любой теме  
- безопасно экспериментировать  
- хранить решения домашних заданий  
- собирать историю обучения для портфолио
