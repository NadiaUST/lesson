# Lesson 12 — Калькулятор стоимости

Небольшой учебный проект: калькулятор, который считает стоимость разработки по выбранным экранам, дополнительным услугам и проценту отката (скидки).

## Что умеет
- Добавлять несколько блоков «экранов» (тип экрана + количество)
- Считать:
  - стоимость экранов
  - стоимость доп. услуг (проценты и фикс)
  - итоговую стоимость
  - стоимость с учетом отката (ползунок `range`)
  - общее количество экранов
- Не дает запускать расчет, если есть незаполненные блоки экранов

## Стек
- HTML
- CSS / SCSS
- JavaScript (Vanilla)
